# Documentation

This folder contains the engineering documentation for the Compact Real-Time Audio Processor.

The goal is to keep documentation useful and lightweight. Additional documents should be added when the project creates a real need for them.

---

## Current Documentation

| Document                                     | Purpose                                                 |
| -------------------------------------------- | ------------------------------------------------------- |
| [Requirements](requirements.md)              | Baseline requirements and stretch goals                 |
| [Architecture](architecture.md)              | Current system architecture and subsystem relationships |
| [Engineering Decisions](decisions/README.md) | Significant architecture and design decisions           |

Testing procedures and results are stored under [`tests/`](../tests/).

---

## Documentation Guidelines

Keep documentation current as the design changes.

Important engineering decisions should not exist only in Discord messages or other informal conversations. If a decision changes the architecture, requirements, or interaction between subsystems, update the relevant documentation.

Large reference files, course documents, presentations, and supporting materials may remain in the team's shared Google Drive rather than being duplicated in this repository.
